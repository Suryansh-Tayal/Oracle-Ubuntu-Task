Oracle Ubuntu Task

Objective

To install and run the Ubuntu operating system using Oracle VirtualBox and verify that the installation works successfully.

Software Used

  • Oracle VirtualBox
  • Ubuntu
  • Windows

Procedure

  1. Opened Oracle VirtualBox.
  2. Created a new virtual machine for Ubuntu.
  3. Selected the Ubuntu ISO file.
  4. Configured the virtual machine settings.
  5. Started the virtual machine.
  6. Followed the Ubuntu installation process.
  7. Completed the installation.
  8. Launched Ubuntu and verified that it was running successfully.
